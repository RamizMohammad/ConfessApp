Confess — Play Store graphics for Canva
=======================================

Files
  Confess-Play-Screenshots-1080x1920.pptx    6 phone screenshots (one per page)
  Confess-Play-Feature-Graphic-1024x500.pptx  feature graphic
  Confess-Play-Icon-512.pptx                  app icon (2 versions)
  layers/                                     every image layer as PNG, in case you want to rebuild by hand
  fonts/                                      Newsreader + Manrope (SIL Open Font License)

Import into Canva
  1. canva.com → Create a design → Import file (or drag the .pptx onto the home page).
  2. Each .pptx opens as one design at the exact pixel size Play Store needs.
  3. Every headline, label and subtitle is a real text box — click to edit.
     The background, phone mockup, note card, avatars and wordmark are separate images you can move or swap.

Fonts
  Manrope is in Canva's library. If headlines show in a different serif, upload
  fonts/newsreader_display.ttf and newsreader_display_italic.ttf in Brand Kit → Fonts (Canva Pro)
  and set the headline to "Newsreader". The amber italic word in each headline is its own run.

Export for Play Console
  Share → Download → PNG. Screenshots: 1080×1920. Feature graphic: 1024×500. Icon: 512×512 (32-bit PNG).
